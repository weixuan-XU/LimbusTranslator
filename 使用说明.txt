================================================================
        《边狱公司》实时翻译  ·  使用说明
================================================================

把游戏界面上的英文实时翻译成中文，译文显示在一个置顶的小窗口里。

它只截屏识别屏幕上的字，不注入游戏、不修改任何游戏文件，
所以没有封号风险。


----------------------------------------------------------------
第一次使用（三步）
----------------------------------------------------------------

【第 1 步】启动

    双击桌面的「边狱公司实时翻译」，或运行 LimbusTranslator.exe。

    · 第一次启动要等 5~10 秒（程序要自我解压）。
      请耐心等，不要重复双击，否则会开出好几个窗口叠在一起。
    · 等一会儿，屏幕右下角会出现一个深色小窗口，那就是它。


【第 2 步】填 API Key

    翻译要用 DeepSeek 的 AI，需要你自己申请一个密钥。

    1. 先按一下 F6
       窗口默认是「鼠标穿透」状态，点击会穿透到游戏上，点不到它。
       按 F6 才能操作（窗口底部状态栏会显示当前状态）。

    2. 在窗口上点右键，选「设置 API Key」。

    3. 到 platform.deepseek.com 注册账号，在「API Keys」页面
       创建一个密钥，复制那串 sk- 开头的字符。

    4. 粘贴进输入框，点「保存」。
       （输入框默认打码，勾选下面的「显示密钥」可以核对有没有粘错。）

    5. 程序会自动测试连接。底部显示
         「连接正常 ·「Confirm」→「确认」」
       就成功了。

    ！要充钱：DeepSeek 的 API 按用量收费，需要先在官网充值。
      本工具用的是最便宜的 deepseek-flash 模型，加上内置的译文缓存，
      正常玩一晚上通常花不了几毛钱。具体价格以官网为准。


【第 3 步】开始翻译

    1. 再按一次 F6，打开鼠标穿透（这样点击就不会被小窗口挡住）。

    2. 回到游戏，按 F2。

    3. 鼠标变成十字，拖拽框选游戏里的英文 ——
       比如对话框、技能说明、任务目标。

    4. 松手就开始翻译，之后每 0.8 秒自动扫描一次。
       对话框换新内容时，译文会自动接在后面。

    框选之后小窗口会自动挪到选区下方，不挡住原文。


----------------------------------------------------------------
按键
----------------------------------------------------------------

    F2          框选一块区域，开始实时翻译
    F4          停止实时翻译 / 再按一次继续
    F3          翻译整个屏幕（只翻一次）
    F6          切换「鼠标穿透」—— 要操作窗口时先按它
    F7          隐藏 / 显示小窗口
    Ctrl+S      复制当前译文
    Ctrl+E      清空窗口里的译文
    Ctrl+Q      退出程序

    左键拖动                        移动窗口
    拖右下角 / 右边缘 / 下边缘      调整窗口大小
    滚轮                            翻看之前的译文
    右键                            打开设置菜单

    说明：这些键游戏一样能收到（只有 F2 会去框选），
          所以不会影响你正常操作游戏。


----------------------------------------------------------------
右键菜单里能调什么
----------------------------------------------------------------

    设置 API Key          换密钥
    测试翻译连接          不确定能不能用时点一下
    界面原文语言          默认 English。游戏是英文就别动它；
                          如果你玩的是中文版游戏、想翻成英文，
                          才改成「中文」。
    译文语言              默认「简体中文」
    带原文对照            在译文上方显示识别到的原文，
                          排查识别错误时很有用
    只看原文（不翻译）    不调用 API，不花钱
    使用术语表            强制使用官方译名（囚徒／人格／异想体…）
    附加翻译要求          给 AI 的额外要求，比如「译文尽量简短」
    背景样式              半透明底板 / 纯文字（不挡画面）
    译文颜色 / 字号 / 底板透明度
    打开共享术语表        编辑 glossary/terms.txt（进 git，保存后自动重载）
    打开本地覆盖          编辑 glossary.local.txt（仅本机，不进 git）
    清空译文缓存


----------------------------------------------------------------
常见问题
----------------------------------------------------------------

■ 按 F2 没反应

    热键需要程序有权限。右键 LimbusTranslator.exe
    → 以管理员身份运行，再试一次。


■ 双击了但什么都没出现

    程序还在解压，等 10 秒再看。如果确实一直不出来：

    1. 打开 F:\LimbusTranslator\ 文件夹
    2. 在地址栏输入 cmd 回车
    3. 敲：LimbusTranslator.exe --selftest
    4. 同目录会生成 selftest.txt，里面写了哪里出了问题


■ 提示「系统没有可用的 OCR 引擎」

    Windows 缺少对应语言的文字识别组件。

    设置 → 时间和语言 → 语言和区域 → 找到对应语言 →
    「语言选项」→ 在「可选语言功能」里安装「光学字符识别」，
    装完重启电脑。


■ 提示「正在用 xxx 引擎代读」

    你系统里没装首选的语言组件，程序退而用了别的顶上。
    能正常用，但识别率会打折。装好对应语言包（见上一条）
    后重启程序即可。


■ 识别出来的字是错的 / 翻译驴唇不对马嘴

    1. 先确认菜单里的「界面原文语言」选对了 ——
       游戏是英文就选 English。
    2. 右键打开「带原文对照」，看它到底识别出了什么。
    3. 如果识别本身就错：把框拉大一点、只框文字本身，
       避开人物立绘和复杂背景。
       游戏文字带描边或特效时识别率会下降，
       这是截图翻译的固有局限，不是程序坏了。


■ 反应太慢

    · 别用 F3 整屏翻译，区域越大识别越慢
    · 打开 config.json，把 live_interval 从 0.8 调大到 1.5


■ 想省钱

    默认已经开了译文缓存和「内容没变就跳过」。
    还可以打开 config.json，把 similarity_threshold 调到 0.95，
    减少重复调用。


----------------------------------------------------------------
文件说明
----------------------------------------------------------------

    LimbusTranslator.exe     主程序
    config.json              你的设置（密钥、语言、颜色等）
    glossary/terms.txt       共享术语表（建议纳入 git，可随时增删改）
    glossary.local.txt       本机私有覆盖（可选，不进 git）
    cache.json               译文缓存

    想恢复到初始状态，把 config.json / cache.json / glossary.local.txt
    删掉即可；共享术语表 glossary/terms.txt 一般保留。
